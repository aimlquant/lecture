# AIML Quant 강의

초급자부터 고급자까지 같은 차시를 함께 볼 수 있게 만든 공개 강의입니다.
각 차시는 핵심 본편과 심화 부록 두 층으로 구성됩니다.

- 공개 사이트: <https://aimlquant.github.io/lecture/>
- 조직 대문: <https://aimlquant.github.io/>
- 스터디: <https://aimlquant.github.io/study/>
- 세미나: <https://aimlquant.github.io/seminar/>
- YouTube: <https://www.youtube.com/@aimlquant>

## 구조

| 경로 | 내용 |
|---|---|
| `html/` | GitHub Pages 에 그대로 배포되는 공개 산출물 |
| `html/courses/<course_id>/` | 코스 하나. 개요와 차시 목록 |
| `html/courses/<course_id>/lessons/<lesson_id>/` | 차시 하나. 페이지·교안·자산 |

## 제작 정본

이 저장소는 공개 가능한 생성물만 보관합니다. 로드맵, 교안 원문, 내레이션 스크립트,
raw 리서치, TTS·영상 하네스는 비공개 형제 저장소 `aimlquant/lecture-materials` 에
있습니다.
