실습 워크시트 · 차시 3

강의 영상을 조립하고 검증하기

실측 오디오 길이와 화면 상태를 30fps 격자에 맞추고, 최종 영상의 중간 경계까지 검증한 뒤 공개 절차를 닫습니다.

원본 내려받기 상세 리포트 발표자료

1. 입력 관문

  • 오디오

    모든 문단이 전사 검증을 통과했고, 길이를 파일에서 다시 측정했는지 봅니다.

  • 정렬

    문장 시작 시각이 단조 증가하고 오디오 길이 안에 있는지 봅니다.

  • 프레임

    모든 화면 상태의 1920×1080 프레임과 ID·상태 번호가 맞는지 봅니다.

2. 타임라인 계산

개별 구간이 아니라 누적 시각을 30fps 경계에 맞춥니다. 각 상태의 길이는 이웃한 누적 프레임의 차이입니다.

3. 세그먼트와 조립

  • 한 상태, 한 세그먼트

    각 정지 프레임이 자신의 정확한 길이를 가진 영상 조각이 됩니다.

  • 동일 규격

    해상도·프레임률·픽셀 형식·코덱을 모두 같게 만듭니다.

  • Copy concat

    이미지 duration을 쓰지 않고, 세그먼트를 다시 인코딩하지 않은 채 잇습니다.

4. 최종 영상 검증

스트림 규격과 총 길이만 보지 않습니다. 각 드러내기 경계 직후 프레임, 긴 무음, 피크, 평균 음량을 재고 처음부터 끝까지 실제로 재생합니다.

5. 보관·공개·롤백

  • 보관

    아카이브 표식·파일시스템·여유 공간을 확인하고 입력과 출력 해시를 원장에 남깁니다.

  • 공개

    자산과 메타데이터를 따로 승인하고, 쿠키 없는 환경에서 영상·임베드·Pages를 확인합니다.

  • 롤백

    실패하면 영상을 비공개로 전환한 뒤 Pages 링크를 제거하는 순서를 준비합니다.
