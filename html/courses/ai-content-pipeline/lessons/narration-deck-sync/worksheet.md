# 슬라이드와 내레이션 맞추기 — 실습 워크시트

목표: 슬라이드 한 장, 내레이션 한 문단, 오디오 한 조각을 같은 ID로 묶고 화면 드러내기
경계를 검증한다.

## 1. 정본 연결

- [ ] 슬라이드의 모든 주장·수치·사례가 `report.md`의 절을 가리킨다.
- [ ] `outline.md`와 `script.md`의 슬라이드 ID 집합이 같다.
- [ ] 두 문서의 ID 순서가 같다.
- [ ] 슬라이드 한 장에 내레이션 문단이 정확히 하나다.
- [ ] 내레이션 문단 하나에 오디오 조각이 정확히 하나다.

- [ ] 도입 문장 동안 어떤 항목도 밝아지지 않는다.
- [ ] 아직 말하지 않은 항목도 자리를 차지하되 흐리게 보인다.
- [ ] 지금 말하는 항목이 가장 밝다.
- [ ] 이미 말한 항목은 맥락으로 남는다.

## 3. 실측 시간 정렬

- [ ] 문장별로 다시 합성하지 않고 문단 오디오에서 시작 시각을 얻었다.
- [ ] 문장 시작 시각이 단조 증가한다.
- [ ] 모든 시작 시각이 오디오 길이 안에 있다.
- [ ] 받아쓰기 경계가 추정값에서 너무 멀면 자동 채택하지 않았다.
- [ ] 화면이 발화보다 조금 먼저 밝아지는지 실제 재생으로 확인했다.

## 4. 최종 크기 렌더 감사

- [ ] 발표자료를 1280×720에서 상태별로 캡처했다.
- [ ] 영상 프레임을 1920×1080에서 확인했다.
- [ ] 글자 넘침·잘림·너무 작은 본문이 없다.
- [ ] 같은 수준의 카드 폭·행·열·중심선·간격이 맞는다.
- [ ] 화살표 끝이 대상 경계의 올바른 면에 닿는다.
- [ ] 커넥터가 글자·라벨·관련 없는 도형을 가로지르지 않는다.
- [ ] 최종 영상의 각 경계 직후 프레임이 기대 상태와 같다.
