실습 워크시트 · 차시 2

슬라이드와 내레이션 맞추기

슬라이드 한 장, 내레이션 한 문단, 오디오 한 조각을 같은 ID로 묶고 화면 드러내기 경계를 검증합니다.

원본 내려받기 상세 리포트 발표자료

1. 정본 연결

  • 근거

    모든 주장·수치·사례가 리포트의 절을 가리키는지 확인합니다.

  • ID

    아웃라인과 대본의 ID 집합과 순서가 정확히 같은지 대조합니다.

  • 생성 단위

    한 장 = 한 문단 = 한 오디오인지 확인합니다.

2. 문장과 화면 상태

필요한 문장 수 = 도입 문장 수 + 화면 항목 수입니다. 도입 동안은 어떤 항목도 밝아지지 않아야 합니다.

  • 아직 말하지 않은 항목

    자리를 차지한 채 흐리게 보입니다.

  • 지금 말하는 항목

    현재 상태에서 가장 밝습니다.

  • 이미 말한 항목

    지나온 맥락으로 밝게 남습니다.

3. 실측 시간 정렬

문장별로 다시 합성하지 않고 문단 오디오에서 시작 시각을 얻습니다. 시작 시각은 단조 증가하고 모두 오디오 길이 안에 있어야 합니다.

4. 최종 크기 렌더 감사

  • 1280×720

    발표자료의 모든 화면 상태에서 글자·격자·드러내기를 봅니다.

  • 1920×1080

    영상 프레임의 가독성과 화살표·라벨 충돌을 봅니다.

  • 최종 영상

    각 경계 직후 프레임이 기대 상태와 같은지 대조합니다.
