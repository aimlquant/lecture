# 강의 영상을 조립하고 검증하기 — 실습 워크시트

목표: 실측 오디오 길이와 화면 상태를 30fps 격자에 맞추고, 최종 영상의 중간 경계까지
검증한 뒤 공개 절차를 닫는다.

## 1. 입력 관문

- [ ] 모든 문단 오디오가 전사 검증을 통과했다.
- [ ] 원장의 오디오 길이를 믿지 않고 파일에서 다시 측정했다.
- [ ] 문장 시작 시각이 단조 증가하고 오디오 길이 안에 있다.
- [ ] 모든 화면 상태의 1920×1080 프레임이 존재한다.
- [ ] 프레임 파일과 슬라이드 ID·상태 번호가 일치한다.

## 2. 타임라인 계산

- [ ] 개별 구간이 아니라 누적 시각을 30fps 프레임 경계에 반올림했다.
- [ ] 각 화면 상태의 길이는 이웃한 누적 프레임의 차이로 구했다.
- [ ] 마지막 상태가 문단 오디오 끝까지 유지된다.
- [ ] 문단 사이 쉼과 마지막 여백을 별도 항목으로 남겼다.
- [ ] 스냅된 총 길이와 원래 총 길이의 차이가 한 프레임보다 작다.

## 3. 세그먼트와 조립

- [ ] 정지 이미지마다 정확한 길이의 영상 세그먼트를 만들었다.
- [ ] 모든 세그먼트의 해상도·프레임률·픽셀 형식·코덱이 같다.
- [ ] 이미지 concat 목록에 `duration`을 쓰지 않았다.
- [ ] 세그먼트는 다시 인코딩하지 않고 copy concat으로 이었다.
- [ ] 오디오를 문단 파일 경계대로 이었다.

## 4. 최종 영상 검증

- [ ] 화면은 H.264, 1920×1080, 30fps, yuv420p다.
- [ ] 소리는 AAC, 48kHz, 단일 채널이다.
- [ ] 오디오·영상·최종 출력 길이의 차이를 기록했다.
- [ ] 각 드러내기 경계 직후 프레임을 기대 프레임과 대조했다.
- [ ] 긴 무음·과도한 피크·지나치게 낮은 평균 음량이 없다.
- [ ] 처음부터 끝까지 실제로 재생해 들었다.

## 5. 보관·공개·롤백

- [ ] 아카이브 표식·파일시스템·여유 공간을 쓰기 전에 확인했다.
- [ ] 콘텐츠·스크립트·오디오·최종 영상 해시를 원장에 남겼다.
- [ ] 자산 승인과 제목·설명·태그 승인을 분리했다.
- [ ] 공개 전 영상 식별자는 소유자 전용 원장에만 남겼다.
- [ ] 공개 뒤 쿠키 없는 환경에서 영상·임베드·Pages 링크를 확인했다.
- [ ] 실패하면 영상 비공개 전환 뒤 Pages 링크를 제거하는 순서를 준비했다.
