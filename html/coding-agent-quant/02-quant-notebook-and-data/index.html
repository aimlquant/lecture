과정 1의 실행 환경을 준비한 분

코딩 에이전트·Python·Jupyter 환경과 차시별 가격 CSV를 사용합니다. 특정 에이전트 제품을 필수로 지정하지 않으며, 도구에 따라 조작이 달라지는 곳은 해당 실습에서 안내합니다. 노트북을 처음 쓰는 분도 영상 1의 시작 묶음으로 출발할 수 있습니다.
