주피터 노트북은 설명과 코드를 담는 문서입니다

Codex가 작성하고, 내가 실행 결과를 확인합니다

설치한 도구와 시작 묶음을 준비합니다

처음에는 notebooks 폴더가 비어 있습니다

만들기를 요청할 때 세 가지를 적습니다

이 한국어 요청문을 그대로 사용합니다

터미널에서 요청문 파일을 Codex에 보냅니다

실습 1 · 요청에서 새 노트북 열기까지

생성 완료 답변 뒤에는 실제 파일을 확인합니다

설명은 읽고, 코드는 실행하고, 출력은 확인합니다

커널은 코드를 실행할 Python입니다

첫 실행은 문장 하나면 충분합니다

실습 2 · 커널 선택과 첫 출력

두 번째 셀에서 두 가격을 준비합니다

세 번째 셀은 앞에서 만든 값을 사용합니다

105를 103으로 고치면 출력도 바로 바뀔까요?

실습 3 · 수정하고 두 셀을 다시 실행하기

수정한 값으로 계산하려면 두 셀을 실행합니다

마지막 셀은 data 폴더의 CSV를 읽습니다

전체 표의 크기와 앞 네 행을 봅니다

실습 4 · CSV 열기와 표 읽기

한 행은 한 날짜, 한 열은 같은 종류의 값입니다

커널을 재시작하고 계산 셀부터 실행하면?

실습 5 · 순서를 건너뛰어 오류 관찰하기

Codex에는 오류가 난 상황을 함께 알려 줍니다

실습 6 · Codex의 안내를 읽고 직접 복구하기

파일에 남은 출력과 커널의 기억을 구별합니다

마지막에는 처음부터 다시 실행합니다
