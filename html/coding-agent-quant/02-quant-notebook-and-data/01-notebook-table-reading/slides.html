세 번째 셀은 앞에서 만든 값을 사용합니다

01세 번째 셀은 앞서 저장한 두 가격으로 변화율을 계산합니다.02105를 100으로 나누고 1을 뺀 뒤 100을 곱하면 5퍼센트입니다.03따라서 가격 입력 셀을 먼저 실행하고 이 계산 셀을 실행해야 합니다.04출력 형식은 소수점 아래 한 자리까지 표시하므로 화면에는 5.0퍼센트가 나옵니다.

01실제 화면에서 수정 전후를 비교하겠습니다.02먼저 100과 105로 실행한 출력과 5.0퍼센트 결과를 봅니다.03코드의 105를 103으로 고친 직후에는 아래 출력이 그대로 남아 있습니다.04가격 입력 셀을 실행해 새 값을 저장하고, 계산 셀도 다시 실행합니다.05이제 가격 변화가 3.0퍼센트로 바뀝니다.

01방금 한 일을 세 단계로 정리해 보겠습니다.02먼저 문서의 비교가격을 105에서 103으로 수정했습니다.03이어서 입력 셀을 실행해 커널이 기억하는 값을 바꿨습니다.04마지막으로 계산 셀을 실행해 새 값으로 계산한 3.0퍼센트를 확인했습니다.05다음에 값을 바꿀 때도 이 순서로 진행합니다.

01표의 한 행은 같은 날짜의 관측값을 모은 것입니다.02날짜 열에는 거래일이 있고, 종가 열에는 그날의 종가가 있습니다.03왼쪽의 0부터 시작하는 번호는 행을 가리키는 인덱스이며 날짜가 아닙니다.04지금은 일부만 미리 보았으므로, 전체 데이터의 결측이나 중복까지 확인한 것은 아닙니다.
