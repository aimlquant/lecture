# 날짜와 시각 정렬 실습

앞 차시와 같은 VS Code 폴더에서 시작합니다. Python 환경에 requirements.txt의 패키지를 설치하고 해당 커널을 선택하세요. 실제 확인 환경은 Python 3.13.5, pandas 3.0.5, ipykernel 7.3.0입니다.

자료는 합성 예제입니다. 예제 휴장일을 실제 거래소 달력으로 사용하지 않습니다. 원본 CSV 네 개는 수정하지 않습니다.

1. 요청-1.txt를 코딩 에이전트에 전달하고 생성한 노트북을 실행합니다. 공란 분류와 잘못된 날짜 결합을 확인합니다.
2. 오전 9시 판단에서 B를 사용할 수 있는지 이유를 먼저 적습니다.
3. 요청-2.txt를 전달하고 수정된 노트북을 다시 엽니다. 외부 파일 변경 안내가 뜨면 에이전트가 저장한 최신 파일을 읽습니다. 예전 편집 내용을 덮어쓰지 않습니다.
4. 다시 실행하여 선택한 ID·공란 사유·미래 매칭 수와 원래 판단 행 수를 확인합니다.
5. exercises.md를 먼저 풀고, 별도 답안 묶음의 교사용 해설과 비교합니다.

완성 노트북은 따라 만들기 뒤 대조용입니다. 긴 구현 코드를 외울 필요는 없습니다. 화면 표는 한국 시각, 저장한 aligned-observations.csv는 UTC이며 둘은 같은 순간을 나타냅니다.
