# 독립 판단 해설

학생은 먼저 별도 독립 판단 문서에 답합니다.

## A

판단 시각은 9/8 00:30Z. X는 2시간 30분 전부터 사용 가능하고 Y는 30분 뒤입니다. X를 고릅니다. Y를 골랐다면 UTC+9에서 UTC로 갈 때 아홉 시간을 빼는지 다시 확인합니다. X의 날짜가 전날이라는 이유로 제외했다면 날짜 대신 실제 시각을 비교합니다.

## B

P를 고르고 Q는 사용 가능 시각 미확인으로 보류합니다. P는 전날 관측이므로 당일 최신 관측이라고 부를 수 없습니다. 9/13 취득은 과거 공개·사용 가능 시각의 증거를 대신하지 않습니다. Q의 시각을 임의로 채웠다면 공란과 보류 사유를 복구합니다.

## C

15일은 거래일 행 누락, 16일은 행의 가격 빈값입니다. 두 경우 모두 원인은 미확인입니다. 달력의 거래일 규칙과 제공처의 원본·수집 기록을 더 확인해야 하며, 휴장이나 통신 오류라고 단정하지 않습니다.
