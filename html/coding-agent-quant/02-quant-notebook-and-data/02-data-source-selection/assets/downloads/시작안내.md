# 에이전트와 첫 EDA

이 시작 묶음은 삼성전자의 2024년 일별 가격·거래량 CSV를 이미 받은 상태에서 시작합니다. 인터넷으로 주가를 다시 받을 필요는 없습니다.

1. 앞선 강의에서 쓰던 VS Code로 압축을 푼 폴더를 엽니다. 코딩 에이전트도 같은 폴더에서 시작합니다. CSV와 요청문을 같은 폴더에 둡니다.
2. `요청-1.txt`를 전달하고 에이전트가 `first-eda.ipynb`를 만들면 VS Code의 탐색기에서 엽니다.
3. 노트북 위쪽의 `Run All`로 셀을 위에서 아래로 실행합니다. 첫 행·마지막 행·행/열 수·열의 의미·기간을 읽어 봅니다.
4. 결과를 읽은 다음 `요청-2.txt`, `요청-3.txt`, `요청-4.txt` 순서로 전달합니다. 매번 **기존 셀을 보존해 끝에 추가**하게 하고 저장 후 다시 실행합니다.
5. 가격·거래량 그래프를 읽고, 관찰한 사실 두 문장과 다음 질문 하나를 먼저 직접 적습니다. `요청-5.txt`의 예시는 자신의 관찰로 바꿔 에이전트에게 근거 확인을 요청합니다.
6. `first-eda.ipynb`와 `관찰기록.md`를 저장합니다. 답안 묶음은 다른 폴더에 풀어 비교합니다.

## 무엇을 확인할까요?

- 한 행은 무엇을 나타내며, 각 열의 값은 어떤 단위인가요?
- 첫 5행을 본 것과 전체 기간을 확인한 것은 어떻게 다른가요?
- 빈값·중복 날짜·날짜 순서에 문제가 있나요? 있다면 어느 행인가요?
- 그래프의 가로축·세로축·단위는 무엇인가요? 관심 있는 지점의 날짜와 원래 값은 무엇인가요?
- 평균과 중앙값은 어떻게 다른가요? 숫자 하나만으로 전체를 설명해도 될까요?
- 내 관찰에는 종목·기간·날짜·수치·단위가 있나요? 원인이나 미래를 추측한 문장이 섞이지 않았나요?

## 실행 환경

앞선 강의에서 사용한 VS Code, Python 확장과 Jupyter 확장을 이어 씁니다. 이 영상은 VS Code의 노트북 편집기와 통합 터미널에서 촬영했습니다. 실제 사용 버전은 Linux, VS Code 1.135.0, Python 3.13.5, Jupyter 확장 2025.9.1, pandas 3.0.5, Matplotlib 3.11.1, Codex CLI 0.153.4입니다.

노트북 오른쪽 위의 커널 선택에서 필요한 패키지를 설치한 Python 환경을 고릅니다. 새 환경이 필요하면 VS Code 통합 터미널에서 다음과 같이 준비합니다.

```bash
python -m venv .venv
# 운영체제에 맞게 .venv를 활성화한 뒤
python -m pip install -r requirements.txt
```

코딩 에이전트가 저장한 `.ipynb` 파일을 VS Code 탐색기에서 엽니다. 위쪽 `Run All`은 전체 실행이고 코드 셀의 `Shift+Enter`는 해당 셀 실행입니다. 에이전트가 파일을 수정했다면 저장된 변경 내용을 다시 불러온 뒤 실행합니다. 원본 CSV는 덮어쓰지 않습니다.

오류가 나면 오류 문구, 바로 전 셀, 사용한 파일명을 에이전트에게 전달하고 최소 수정 후 다시 실행합니다. 결과를 재현할 때는 `Restart` 후 `Run All`을 사용합니다. 자세한 원리는 앞 차시를 참고합니다.
