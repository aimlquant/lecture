포트폴리오로 묶기

앞서 검증을 통과한 한국 전략들의 상관을 보고 자본을 배분합니다. 국면이 바뀌었을 때 한국 표본에서 전략이 언제 깨졌는지 확인하고 은퇴 판단을 다룹니다.

이 과정의 실습 노트북도 과정 04 첫 백테스트 — 규칙 하나로 끝까지 에서 만든 표준 백테스트 하네스 를 그대로 씁니다. 거래별 감사표, 미래 구간을 잘라 보는 룩어헤드 검사, 반증 테스트가 같은 자리에 따라옵니다.

  • 4구성 영상
  • 15분영상당 최대 길이
  • 팩터 모델 · 리스크와 자금관리선행 과정

과정 전체 흐름을 먼저 고정하고 영상별로 제작합니다. 아래 카드는 각 영상의 순서와 현재 공개 범위를 보여 줍니다. 상세 리포트·슬라이드·실습 자료는 해당 영상을 제작하고 검토할 때 영상별로 각각 연결합니다.
