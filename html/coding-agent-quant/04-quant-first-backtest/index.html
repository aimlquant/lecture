첫 백테스트 — 규칙 하나로 끝까지

KODEX 200 에 이동평균 규칙 하나를 걸어 명세부터 백테스트까지 끝까지 돌립니다. 신호 시각과 체결 시각을 감사표로 남기고, 열 줄짜리 데이터로 손계산과 대조합니다.

이 과정에서 표준 백테스트 하네스 를 만듭니다. 이후 모든 과정의 실습 노트북이 같은 모양을 물려받습니다. 거래별 감사표, 미래 구간을 잘라 보는 룩어헤드 검사, 반증 테스트가 같은 자리에 따라옵니다.

  • 5구성 영상
  • 15분영상당 최대 길이
  • 성과를 재는 법선행 과정

과정 전체 흐름을 먼저 고정하고 영상별로 제작합니다. 아래 카드는 각 영상의 순서와 현재 공개 범위를 보여 줍니다. 상세 리포트·슬라이드·실습 자료는 해당 영상을 제작하고 검토할 때 영상별로 각각 연결합니다.
