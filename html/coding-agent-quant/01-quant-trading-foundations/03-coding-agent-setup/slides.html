01코덱스는 비주얼 스튜디오 코드의 확장 기능과 터미널에서 쓰는 명령줄 도구로 나뉩니다.02다음 실습에서는 요청과 파일 변화를 한 화면에서 볼 수 있는 확장 기능을 사용합니다.03명령줄 도구인 코덱스 씨엘아이는 잠시 뒤 터미널에서 설치 여부를 확인할 때 사용하겠습니다.

터미널에서 Codex 버전을 확인한다

01터미널을 열고 화면에 보이는 버전 확인 명령을 입력합니다.02코덱스 씨엘아이와 버전 번호가 화면처럼 나오면 설치가 끝난 것입니다.03설치 방법은 바뀔 수 있으므로 실습할 때 오픈에이아이 공식 문서를 다시 확인합니다.

강의 폴더에 Python 환경을 만든다

01다음으로 강의용 폴더에서 사용할 파이썬 가상 환경을 만들겠습니다.

Python 가상 환경을 먼저 이해하자

01파이썬 환경을 이해하는 데 필요한 네 용어부터 살펴보겠습니다.02파이썬은 앞으로 퀀트 코드를 작성할 프로그래밍 언어입니다.03인터프리터는 그 코드를 읽고 실행하는 프로그램입니다.04가상 환경은 프로젝트별로 필요한 파이썬 도구를 따로 모아 둔 공간입니다.05이 강의에서는 가상 환경 폴더에 화면과 같은 이름을 사용합니다.

VS Code와 Jupyter에서 같은 .venv를 선택한다

01만드는 순서는 간단합니다.02먼저 컴퓨터에 설치된 파이썬으로 강의 폴더 안에 가상 환경을 만듭니다.03그런 다음 비주얼 스튜디오 코드와 주피터에서 그 환경을 선택합니다.04그래야 코드와 노트북이 같은 파이썬 환경에서 실행됩니다.

노트북의 코드는 커널이 실행한다

01주피터 화면에서 자주 보는 네 용어를 알아보겠습니다.02노트북은 설명과 코드와 실행 결과를 한 파일에 담는 문서입니다.03셀은 그 문서에서 설명이나 코드를 입력하는 한 칸입니다.04커널은 셀의 코드를 읽고 결과를 돌려주는 프로그램입니다.05전체 실행 버튼은 모든 셀을 위에서부터 차례로 실행합니다.

확인용 노트북은 이 차시에서 직접 만든다

01이번에 사용할 확인용 노트북은 따로 내려받는 파일이 아닙니다.02왼쪽 탐색기에서 화면에 보이는 이름으로 폴더를 만듭니다.03그 안에 화면에 보이는 이름으로 새 파일을 만듭니다.04파일을 누르면 주피터 노트북 편집기가 열립니다.

.venv를 고른 뒤 Run All을 누른다

01노트북 오른쪽 위에서 강의용 폴더의 가상 환경을 커널로 고릅니다.02첫 번째 셀에 화면의 코드를 붙여 넣고 전체 실행 버튼을 누릅니다.03코드 아래에 환경 확인 완료, 파이썬 버전, 작업 폴더라는 세 줄이 나오면 연결이 제대로 된 것입니다.

문제가 생긴 지점을 찾는다

01내 화면이 강의와 다르거나 실행이 멈추면 문제가 생긴 지점을 찾아보겠습니다.

문제는 세 단계로 찾는다

01문제가 생기면 앞에서부터 세 단계로 확인합니다.02먼저 강의 화면과 내 화면을 비교합니다.03다음으로 처음 보이지 않는 단계가 어디인지 찾습니다.04마지막으로 그 단계만 다시 확인합니다.

막힌 단계만 다시 확인한다

01문제가 생긴 단계만 다시 확인해 보겠습니다.02폴더명이 없으면 폴더 열기 메뉴로 다시 엽니다.03코덱스가 열리지 않으면 게시자와 식별자를 봅니다.04가상 환경이 없으면 만들기가 끝났는지 봅니다.05커널 목록에 없다면 인터프리터에서 다시 선택합니다.06셀이 실행되지 않으면 커널과 연결 패키지를 확인합니다.

고친 뒤 세 화면만 다시 확인한다

01문제를 고쳤다면 세 화면만 다시 봅니다.02왼쪽에 강의용 폴더와 코덱스 입력창이 함께 보이는지 확인합니다.03노트북 오른쪽 위에 가상 환경이 선택돼 있는지 봅니다.04마지막으로 전체 실행 버튼을 눌렀을 때 코드 아래에 세 줄의 결과가 나오는지 확인합니다.
