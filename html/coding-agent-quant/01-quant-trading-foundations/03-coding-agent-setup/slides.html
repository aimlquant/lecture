Python 가상 환경을 먼저 이해하자

01파이썬 환경을 이해하는 데 필요한 네 용어부터 살펴보겠습니다.02파이썬은 앞으로 퀀트 코드를 작성할 프로그래밍 언어입니다.03인터프리터는 그 코드를 읽고 실행하는 프로그램입니다.04가상 환경은 프로젝트별로 필요한 파이썬 도구를 따로 모아 둔 공간입니다.05이 강의에서는 가상 환경 폴더에 화면과 같은 이름을 사용합니다.

VS Code와 Jupyter에서 같은 .venv를 선택한다

01만드는 순서는 간단합니다.02먼저 컴퓨터에 설치된 파이썬으로 강의 폴더 안에 가상 환경을 만듭니다.03그런 다음 비주얼 스튜디오 코드와 주피터에서 그 환경을 선택합니다.04그래야 코드와 노트북이 같은 파이썬 환경에서 실행됩니다.

노트북의 코드는 커널이 실행한다

01주피터 화면에서 자주 보는 네 용어를 알아보겠습니다.02노트북은 설명과 코드와 실행 결과를 한 파일에 담는 문서입니다.03셀은 그 문서에서 설명이나 코드를 입력하는 한 칸입니다.04커널은 셀의 코드를 읽고 결과를 돌려주는 프로그램입니다.05전체 실행 버튼은 모든 셀을 위에서부터 차례로 실행합니다.

확인용 노트북은 이 차시에서 직접 만든다

01이번에 사용할 확인용 노트북은 따로 내려받는 파일이 아닙니다.02왼쪽 탐색기에서 화면에 보이는 이름으로 폴더를 만듭니다.03그 안에 화면에 보이는 이름으로 새 파일을 만듭니다.04파일을 누르면 주피터 노트북 편집기가 열립니다.

.venv를 고른 뒤 Run All을 누른다
