VS Code 실습 환경 점검표

설치 여부만 보지 않고, 올바른 작업 폴더와 가상 환경에서 실제 코드가 실행되는지 확인합니다.

설치 점검표 내려받기환경 확인 노트북상세 리포트발표자료

  • 폴더와 도구

    강의 전용 폴더를 열고 Codex 확장 기능과 CLI, Python·Jupyter 확장 기능을 확인합니다.

  • 가상 환경과 커널

    폴더 안의 .venv를 만들고 같은 환경을 Python 인터프리터와 노트북 커널로 선택합니다.

  • 마지막 확인

    환경 확인 노트북을 열어 모든 셀을 실행하고 오류 없이 결과가 나오는지 확인합니다.
