    프로그램을 설치하고 강의용 폴더를 만든다

    설치 파일은 공식 페이지에서 받는다

    먼저 VS Code 공식 다운로드 페이지에서 자신의 운영체제에 맞는 설치 파일을 받아 설치한다. Python도 Python 공식 다운로드 페이지에서 받을 수 있다. 회사나 학교에서 관리하는 컴퓨터라면 프로그램 설치 권한이 없을 수 있으므로 관리자에게 먼저 확인한다.

    뒤에서 터미널도 잠깐 사용한다. 터미널은 명령어를 글자로 입력해 프로그램을 다루는 창이다. 운영체제에 따라 같은 Python을 부르는 명령어가 조금 다를 수 있다.

    표 2운영체제에 따라 달라질 수 있는 설치 부분. 이후의 VS Code 실습 순서는 같다.
    운영체제 VS Code와 Python을 설치할 때 알아둘 점 뒤에서 보이는 작은 차이
    Windows 공식 설치 프로그램을 차례로 실행한다. Python 설치 화면에 Add Python to PATH가 보이면 체크한다 터미널 명령이 py 또는 python으로 시작할 수 있다
    macOS 자신의 Mac이 Apple Silicon인지 Intel인지 확인한 뒤 맞는 설치 파일을 고른다 터미널 명령은 보통 python3으로 시작한다
    Linux 배포판의 소프트웨어 센터나 VS Code 공식 패키지를 이용한다. Python이 이미 설치된 경우도 많다 배포판에 따라 Python 환경을 나눠 쓰기 위한 패키지를 따로 설치할 수 있다

    새 폴더를 만들고 이름을 정한다

    이제 문서나 바탕 화면처럼 찾기 쉬운 곳에 빈 폴더를 하나 만든다. 폴더 이름은 강의 화면과 똑같이 course-01-practice로 정한다. 이 폴더는 앞으로 Codex가 파일을 만들고 Python 코드를 실행할 강의 전용 작업 공간이다. 다른 문서나 개인 파일은 넣지 않는다.

    강의용 폴더를 VS Code에서 연다

    메뉴를 누르는 순서대로 따라가면 된다

    VS Code를 실행하면 처음에는 빈 시작 화면이 보일 수 있다. 다음 순서로 방금 만든 폴더를 연다.

    1. 화면 위쪽에서 File 메뉴를 누른다.
    2. 메뉴에서 Open Folder...를 누른다.
    3. 앞에서 만든 course-01-practice를 한 번 눌러 선택한다.
    4. Open 또는 Select Folder 버튼을 누른다.

    처음 여는 폴더라면 VS Code가 이 폴더의 작성자를 믿을 수 있는지 물을 수 있다. 지금은 내가 방금 만든 빈 폴더이므로 폴더 이름을 다시 확인하고 Yes, I trust the authors를 누른다. 인터넷에서 내려받은 낯선 폴더라면 내용을 확인하기 전까지 같은 버튼을 바로 누르지 않는다.

    여기까지가 뒤 실습의 출발점이다. Codex는 이 폴더 안의 파일을 바탕으로 작업하고, 우리가 만드는 Python 환경과 노트북도 모두 이 안에 둔다.

    핵심 본편 · core

    Codex를 설치하고 VS Code 안에서 연다

    앞에서 설명한 확장 기능을 VS Code에 추가한다

    VS Code 왼쪽의 블록 모양 Extensions 아이콘을 누른다. 확장 기능은 스마트폰의 앱처럼 VS Code에 필요한 기능을 더해 주는 프로그램이다. 검색창에 @id:openai.chatgpt를 입력하고 다음 두 가지를 확인한다.

    • 게시자(Publisher)가 OpenAI인가
    • 식별자(Identifier)가 openai.chatgpt인가

    이름이 비슷한 다른 확장 기능을 잘못 고르지 않도록 두 항목을 확인한 뒤 Install을 누른다.

    설치가 끝나면 왼쪽의 Codex 아이콘을 누른다. 아이콘이 보이지 않으면 Command Palette를 열어 Codex: Open Codex Sidebar를 찾는다. Command Palette는 VS Code의 기능 이름을 검색해 실행하는 창이다. Windows와 Linux에서는 Ctrl+Shift+P, macOS에서는 Command+Shift+P로 열 수 있다.

    ChatGPT 계정으로 로그인하는 동안 이메일, 비밀번호, 인증 코드가 나타날 수 있다. 강의 영상은 이 구간에서 잠시 멈추고, 로그인 뒤 빈 Codex 화면부터 다시 시작한다.

    Codex CLI도 함께 설치해 둔다

    Codex는 두 가지 화면에서 사용할 수 있다. 이번 과정의 본편은 초보자가 파일 변화를 보기 쉬운 VS Code 확장 기능을 사용한다. Codex CLI는 터미널이라는 글자 입력 창에서 Codex를 사용하는 방법이다. CLI는 명령어를 글자로 입력해 프로그램을 다루는 방식을 뜻한다. 다음 영상에서 꼭 쓰지는 않지만, 뒤에서 터미널 작업을 배울 때 바로 시작할 수 있도록 이번에 함께 설치한다.

    터미널을 열고 자신의 운영체제에 맞는 명령 한 줄을 붙여 넣는다. 이 명령은 반드시 Codex CLI 공식 문서에서 다시 확인한 뒤 사용한다.

    Windows PowerShell:
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

macOS / Linux Terminal:
curl -fsSL https://chatgpt.com/codex/install.sh | sh

    설치 뒤 새 터미널을 열고 다음 명령을 입력한다.

    codex --version

    codex와 버전 번호가 나오면 설치된 것이다. 처음 codex를 실행하면 로그인을 안내한다. VS Code 확장 기능과 CLI는 같은 Codex를 서로 다른 화면에서 사용하는 방법이며, 다음 영상의 실습은 계속 VS Code 확장 기능으로 진행한다.

    핵심 본편 · core

    이 프로젝트에서 쓸 Python 환경을 따로 만든다

    가상 환경은 프로젝트마다 따로 두는 Python 도구 상자다

    먼저 Extensions에서 Microsoft가 배포한 Python과 Jupyter 확장 기능을 설치한다. 검색창에 각각 @id:ms-python.python, @id:ms-toolsai.jupyter를 입력하면 정확한 확장 기능을 찾을 수 있다.

    Python을 설치하면 컴퓨터에는 Python 코드를 읽고 실행하는 프로그램이 생긴다. 이것을 Python 인터프리터라고 부른다. 한 컴퓨터에서 여러 프로젝트를 만들다 보면 프로젝트마다 필요한 도구의 버전이 달라질 수 있다. 그래서 이번 폴더에서 사용할 Python 도구만 따로 모아 두는데, 이 공간을 가상 환경이라고 한다.

    .venv는 가상 환경 폴더에 흔히 붙이는 이름이다. 앞의 점 때문에 macOS나 Linux의 파일 탐색기에서는 숨겨진 폴더처럼 보일 수 있지만, VS Code에서는 선택할 수 있다. 가상 환경을 지우더라도 원본 코드는 사라지지 않으며, 필요한 도구를 다시 설치해 만들 수 있다.

    Command Palette를 열고 다음 순서로 선택한다.

    1. Python: Create Environment를 찾는다.
    2. Venv를 선택한다.
    3. 컴퓨터에 설치된 Python을 선택한다.
    4. 잠시 기다린 뒤 왼쪽 탐색기에 .venv가 생겼는지 확인한다.
    5. Python: Select Interpreter를 열어 방금 만든 .venv를 선택한다.

    터미널 사용이 익숙하다면 다음 명령으로도 같은 가상 환경을 만들 수 있다. 처음 따라 하는 수강생은 위의 VS Code 메뉴만 사용해도 된다.

    Windows:      py -m venv .venv
macOS/Linux: python3 -m venv .venv
    심화 부록 · deep

    Jupyter 노트북에서 Python 코드를 실행한다

    노트북, 셀, 커널을 차례로 연결한다

    강의용 폴더 안에 notebooks라는 폴더를 만들고 그 안에 environment-check.ipynb 파일을 만든다. 이 파일이 앞에서 설명한 Jupyter 노트북이다. 노트북 안에서 코드를 입력하는 사각형 한 칸을 셀이라고 한다.

    셀을 실제로 실행하는 Python 프로그램은 커널이라고 부른다. 쉽게 말해 셀이 입력 칸이라면 커널은 그 칸의 코드를 읽고 결과를 돌려주는 실행 담당자다. 우리가 만든 .venv를 커널로 선택해야 같은 Python 환경에서 코드가 실행된다.

    노트북 오른쪽 위의 Select Kernel을 누르고 Python Environments를 선택한 뒤 .venv를 고른다.

    이때 IPyKernel을 설치하라는 안내가 나올 수 있다. IPyKernel은 우리가 고른 Python 환경을 Jupyter 노트북과 연결해 주는 작은 Python 패키지다. VS Code의 설치 버튼을 눌러 진행하면 된다. 버튼이 보이지 않을 때만 .venv가 선택된 터미널에서 다음 명령을 실행한다.

    python -m pip install ipykernel

    Python 코드가 실제로 실행되는지 확인한다

    첫 번째 셀에 다음 코드를 붙여 넣는다. 지금은 문법을 외울 필요가 없다. 선택한 Python이 실제로 동작하는지 확인하기 위한 짧은 코드다.

    import platform

print("환경 확인 완료")
print(f"Python {platform.python_version()}")
print("작업 폴더: course-01-practice")

    오른쪽 위에 .venv와 Python 버전이 보이는지 확인한 뒤 Run All을 누른다. Run All은 노트북 안의 모든 셀을 위에서부터 차례로 실행하는 버튼이다. 코드 아래에 세 줄의 결과가 나오면 Python과 Jupyter가 제대로 연결된 것이다.

    환경을 확인한 뒤 폴더 안에는 다음과 같은 파일이 보인다.

    course-01-practice/
├── .venv/
└── notebooks/
    └── environment-check.ipynb

    다음 영상에서는 이 폴더에 가격 데이터와 새 노트북을 만든다. 지금 실행한 코드는 환경이 준비됐는지만 확인한다. 투자 데이터가 정확한지, 전략이 좋은지는 아직 판단하지 않는다.
