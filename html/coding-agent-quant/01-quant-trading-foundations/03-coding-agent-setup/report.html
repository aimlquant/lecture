    프로그램을 설치하고 강의용 폴더를 만든다

    공식 홈페이지에서 설치 파일을 받는다

    먼저 VS Code 공식 다운로드 페이지에서 자신의 운영체제에 맞는 설치 파일을 받아 설치한다. Python도 Python 공식 다운로드 페이지에서 받을 수 있다. 회사나 학교에서 관리하는 컴퓨터라면 프로그램 설치 권한이 없을 수 있으므로 관리자에게 먼저 확인한다.

    뒤에서 터미널도 잠깐 사용한다. 터미널은 명령어를 글자로 입력하는 창이다. 같은 Python을 실행하더라도 운영체제에 따라 명령어가 조금씩 다를 수 있다.

    표 2운영체제별 설치 차이. VS Code에서 진행하는 실습 순서는 같다.
    운영체제 VS Code와 Python을 설치할 때 알아둘 점 뒤에서 보이는 작은 차이
    Windows 공식 설치 프로그램을 차례로 실행한다. Python 설치 화면에 Add Python to PATH가 보이면 체크한다 터미널 명령이 py 또는 python으로 시작할 수 있다
    macOS 자신의 Mac이 Apple Silicon인지 Intel인지 확인한 뒤 맞는 설치 파일을 고른다 터미널 명령은 보통 python3으로 시작한다
    Linux 배포판의 소프트웨어 센터나 VS Code 공식 패키지를 이용한다. Python이 이미 설치된 경우도 많다 배포판에 따라 Python 환경을 나눠 쓰기 위한 패키지를 따로 설치할 수 있다

    VS Code에 Codex를 설치한다

    OpenAI가 만든 확장 기능인지 확인한다

    VS Code 왼쪽의 블록 모양 Extensions 아이콘을 누른다. 확장 기능은 스마트폰의 앱처럼 VS Code에 필요한 기능을 더해 주는 프로그램이다. 검색창에 @id:openai.chatgpt를 입력하고 다음 두 가지를 확인한다.

    • 게시자(Publisher)가 OpenAI인가
    • 식별자(Identifier)가 openai.chatgpt인가

    이름이 비슷한 확장 기능이 있을 수 있으므로 두 항목을 확인한 뒤 Install을 누른다.

    설치가 끝나면 왼쪽의 Codex 아이콘을 누른다. 아이콘이 보이지 않으면 Command Palette를 열어 Codex: Open Codex Sidebar를 찾는다. Command Palette는 VS Code의 기능 이름을 검색해 실행하는 창이다. Windows와 Linux에서는 Ctrl+Shift+P, macOS에서는 Command+Shift+P로 열 수 있다.

    ChatGPT 계정으로 로그인하는 동안 이메일, 비밀번호, 인증 코드가 나타날 수 있다. 강의 영상은 이 구간에서 잠시 멈추고, 로그인 뒤 빈 Codex 화면부터 다시 시작한다.

    터미널에서 쓸 Codex도 준비한다

    Codex는 VS Code 안에서도, 터미널에서도 사용할 수 있다. 이번 과정에서는 파일 변화를 보기 쉬운 VS Code 확장 기능을 주로 사용한다. Codex CLI는 터미널에 명령어를 입력해 Codex를 사용하는 도구다. 다음 영상에서 바로 쓰지는 않지만, 이후 터미널 실습에서도 사용할 수 있도록 이번에 함께 설치한다.

    터미널을 열고 자신의 운영체제에 맞는 명령 한 줄을 붙여 넣는다. 이 명령은 반드시 Codex CLI 공식 문서에서 다시 확인한 뒤 사용한다.

    Windows PowerShell:
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

macOS / Linux Terminal:
curl -fsSL https://chatgpt.com/codex/install.sh | sh

    설치 뒤 새 터미널을 열고 다음 명령을 입력한다.

    codex --version

    codex-cli와 버전 번호가 나오면 설치가 끝난 것이다. 처음 codex를 실행하면 로그인 안내가 나온다. VS Code 확장 기능과 CLI는 같은 Codex를 사용하는 두 가지 방법이며, 다음 영상의 실습은 VS Code 확장 기능으로 진행한다.

    강의 폴더에 Python 가상 환경을 만든다

    가상 환경은 이 폴더에서만 쓰는 Python 도구 모음이다

    먼저 Extensions에서 Microsoft가 배포한 Python과 Jupyter 확장 기능을 설치한다. 검색창에 각각 @id:ms-python.python, @id:ms-toolsai.jupyter를 입력하면 정확한 확장 기능을 찾을 수 있다.

    Python을 설치하면 Python 코드를 읽고 실행하는 프로그램도 함께 설치된다. 이것을 Python 인터프리터라고 한다. 여러 프로젝트를 만들다 보면 프로젝트마다 필요한 도구와 버전이 달라질 수 있다. 서로 섞이지 않도록 이번 폴더에서 쓸 Python 도구를 따로 모아 둔 공간이 가상 환경이다.

    .venv는 가상 환경 폴더에 흔히 쓰는 이름이다. 앞의 점 때문에 macOS나 Linux의 파일 탐색기에서는 숨겨질 수 있지만 VS Code에서는 선택할 수 있다. 이 폴더를 지워도 작성한 코드는 사라지지 않으며, 필요할 때 가상 환경만 다시 만들 수 있다.

    Command Palette를 열고 다음 순서로 선택한다.

    1. Python: Create Environment를 찾는다.
    2. Venv를 선택한다.
    3. 컴퓨터에 설치된 Python을 선택한다.
    4. 잠시 기다린 뒤 왼쪽 탐색기에 .venv가 생겼는지 확인한다.
    5. Python: Select Interpreter를 열어 방금 만든 .venv를 선택한다.

    터미널 사용이 익숙하다면 다음 명령으로도 같은 가상 환경을 만들 수 있다. 처음 따라 하는 수강생은 위의 VS Code 메뉴만 사용해도 된다.

    Windows:      py -m venv .venv
macOS/Linux: python3 -m venv .venv

    Jupyter 노트북에서 첫 코드를 실행한다

    노트북·셀·커널이 어떻게 이어지는지 알아보자

    이번 차시에서 사용할 확인용 노트북은 따로 내려받지 않는다. VS Code에서 직접 새 파일로 만든다.

    1. VS Code 왼쪽 탐색기에서 새 폴더 버튼을 누르고 notebooks를 입력한다.
    2. 방금 만든 notebooks 폴더를 선택한 뒤 새 파일 버튼을 누른다.
    3. 파일 이름을 environment-check.ipynb로 입력하고 Enter를 누른다.
    4. 왼쪽 탐색기에서 그 파일을 누른다. Jupyter 확장 기능이 설치돼 있으면 노트북 편집기가 열린다.

    모든 준비를 마치면 그림 9의 왼쪽 탐색기처럼 .venv, notebooks, environment-check.ipynb가 차례로 보인다. 처음부터 이 파일들이 들어 있는 폴더를 받는 것이 아니라, 이번 차시를 따라 하면서 직접 만드는 것이다.

    .ipynb는 Jupyter 노트북 파일에 붙는 확장자다. 이 파일에서는 설명과 코드, 실행 결과를 한 화면에서 볼 수 있다. 노트북 안에서 코드를 입력하는 사각형 한 칸을 셀이라고 한다.

    셀의 코드를 실제로 실행하는 프로그램을 커널이라고 한다. 셀이 코드를 적는 칸이라면, 커널은 그 코드를 읽고 결과를 돌려주는 실행 담당자다. 앞에서 만든 .venv를 커널로 선택해야 같은 Python 환경에서 코드가 실행된다.

    노트북 오른쪽 위의 Select Kernel을 누르고 Python Environments를 선택한 뒤 .venv를 고른다.

    이때 IPyKernel을 설치하라는 안내가 나올 수 있다. IPyKernel은 선택한 Python 환경을 Jupyter 노트북과 연결하는 패키지다. VS Code에 설치 버튼이 보이면 그대로 누르면 된다. 버튼이 보이지 않을 때만 .venv가 선택된 터미널에서 다음 명령을 실행한다.

    python -m pip install ipykernel

    짧은 코드로 설치 상태를 확인한다

    첫 번째 셀에 다음 코드를 붙여 넣는다. 지금은 문법을 외울 필요가 없다. 방금 선택한 Python이 제대로 실행되는지만 확인하는 코드다.

    import platform

print("환경 확인 완료")
print(f"Python {platform.python_version()}")
print("작업 폴더: course-01-practice")

    오른쪽 위에 .venv와 Python 버전이 보이는지 확인한 뒤 Run All을 누른다. Run All은 노트북의 모든 셀을 위에서부터 실행하는 버튼이다. 코드 아래에 세 줄의 결과가 나오면 Python과 Jupyter가 제대로 연결된 것이다.

    환경을 확인한 뒤 폴더 안에는 다음과 같은 파일이 보인다.

    course-01-practice/
├── .venv/
└── notebooks/
    └── environment-check.ipynb

    다음 영상에서는 이 폴더에 가격 데이터와 새 노트북을 만든다. 지금 실행한 코드는 프로그램이 제대로 연결됐는지만 확인한다. 투자 데이터의 정확성이나 전략의 성과를 확인한 것은 아니다.

    버튼이 보이지 않거나 코드가 실행되지 않더라도 프로그램을 전부 지울 필요는 없다. 아래 순서대로 확인하면 어느 단계에서 문제가 생겼는지 찾을 수 있다.

    표 3자주 생기는 문제와 먼저 확인할 항목.
    문제 먼저 확인할 곳 해 볼 일
    왼쪽에 강의용 폴더명이 없다 VS Code가 다른 폴더를 열었는지 본다 File → Open Folder...로 course-01-practice를 다시 연다
    Codex 화면이 열리지 않는다 게시자가 OpenAI이고 식별자가 openai.chatgpt인지 본다 확장 기능을 다시 확인하고 Codex 아이콘 또는 Command Palette로 연다

    .venv가 커널 목록에 없다 Python 인터프리터가 .venv로 선택됐는지 본다 .venv를 다시 선택하고 노트북을 다시 연다
    셀이 계속 실행 중이거나 오류가 난다 커널 이름과 IPyKernel 안내를 본다 .venv를 다시 고르고 IPyKernel 설치를 마친 뒤 Run All을 누른다

    문제를 고친 뒤에는 처음부터 같은 내용을 다시 확인할 필요가 없다. 다음 세 화면만 이어서 확인한다.

    1. 왼쪽 탐색기에 강의용 폴더가 보이고 그 옆에 Codex 입력창이 열려 있다.
    2. 노트북 오른쪽 위에 .venv가 선택돼 있다.
    3. Run All을 누르면 코드 아래에 세 줄의 결과가 나온다.

    세 화면이 모두 보이면 준비가 끝난다. 다음 영상에서는 같은 폴더에서 Codex에게 KODEX 200 가격 파일과 Jupyter 노트북을 만들어 달라고 요청하고, 만들어진 파일과 실행 결과를 직접 확인한다.
