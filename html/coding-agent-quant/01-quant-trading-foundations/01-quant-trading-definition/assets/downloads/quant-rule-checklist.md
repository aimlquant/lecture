# 퀀트 규칙 점검표

투자 아이디어를 컴퓨터가 같은 방식으로 다시 판단할 수 있는 규칙으로 바꿀 때 사용한다.
빈칸을 채운 뒤, 다른 사람이 같은 입력으로 같은 판단을 내릴 수 있는지 확인한다.

## 1. 입력 자료

- 종목 또는 투자 대상:
- 사용할 자료와 필드:
- 자료를 읽는 시점:
- 결측값이나 휴장일을 처리하는 방법:

## 2. 판단 기준

- 계산할 값:
- 계산 순서:
- 진입 조건과 임계값:
- 청산 조건과 임계값:
- `최근`, `크다`, `뚜렷하다`처럼 수치로 바꿔야 할 표현:

## 3. 행동

- 조건이 맞을 때 할 일:
- 조건이 맞지 않을 때 할 일:
- 보유 중일 때 할 일:
- 주문 크기 또는 포지션 크기를 정하는 방법:

## 4. 같은 판단을 다시 만들 수 있는지 확인

- [ ] 같은 입력을 주면 같은 결과가 나온다.
- [ ] 사람이 추가로 차트를 해석하지 않아도 된다.
- [ ] 당시 알 수 있었던 자료만 사용한다.
- [ ] 아이디어의 문장과 코드의 조건이 서로 맞는다.
- [ ] 과거 데이터에 같은 규칙을 다시 적용할 수 있다.

## 5. 아직 확인하지 않은 것

- [ ] 데이터 편향과 오류
- [ ] 거래비용과 슬리피지
- [ ] 수익률과 위험
- [ ] 다른 기간과 다른 종목에서의 결과
- [ ] 실제 주문 전송과 운영 안전성

이 점검표를 모두 채웠다는 사실만으로 수익성이 증명되지는 않는다. 이 단계의 목적은 투자
아이디어를 검증할 수 있는 전략 후보로 분명하게 정의하는 것이다.
