# 코딩 에이전트 작업 요청문 양식

대괄호 안의 내용을 자신의 작업에 맞게 바꾼다. 구현 방법을 모두 아는 것보다, 왜 필요한지와
어디까지 작업할지, 무엇을 확인할지를 구체적으로 적는 것이 중요하다.

```text
현재 연 [작업 폴더 이름] 폴더 안에서만 작업해 주세요.

목적:
- [이 작업으로 확인하거나 해결하려는 내용]

현재 상황:
- [관련 파일과 폴더]
- [이미 시도한 일과 현재 보이는 오류]

만들거나 고칠 결과물:
- [파일 경로 1]
- [파일 경로 2]

지켜야 할 범위:
- [바꾸지 말아야 할 파일이나 폴더]
- [사용해야 할 데이터·버전·기간]
- [인터넷 연결, 패키지 설치, 삭제 전에 확인할 사항]

확인 방법:
- [실행할 명령 또는 노트북 실행 순서]
- [성공했을 때 화면이나 파일에서 보여야 할 값]
- [실패하면 알려 줄 오류 조건]

완료 보고:
- 만든 파일과 바꾼 내용을 요약해 주세요.
- 실제로 실행한 명령과 확인한 결과를 알려 주세요.
- 아직 확인하지 못한 부분과 사람이 판단해야 할 부분을 구분해 주세요.
```

## 작업을 시작하기 전에

- [ ] 목적과 결과물이 서로 이어진다.
- [ ] 작업 폴더와 수정 범위가 적혀 있다.
- [ ] 종목, 기간, 파일 형식처럼 결과를 바꾸는 조건이 적혀 있다.
- [ ] 되돌리기 어려운 삭제나 외부 전송은 별도로 확인하게 했다.

## 작업이 끝난 뒤

- [ ] 요청한 파일이 실제로 생겼다.
- [ ] 변경 내용이 정한 범위 안에 있다.
- [ ] 명령이나 노트북을 직접 실행해 결과를 확인했다.
- [ ] 화면의 값과 처음 요청한 조건이 맞는다.
- [ ] 에이전트의 완료 요약과 실제 파일·실행 결과가 일치한다.
