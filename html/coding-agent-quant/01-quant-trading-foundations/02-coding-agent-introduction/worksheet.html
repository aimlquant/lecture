코딩 에이전트 작업 요청 템플릿

목적, 작업 범위, 원하는 결과물, 확인 방법을 빠뜨리지 않고 적는 양식입니다. 에이전트가 끝났다고 말한 뒤 사람이 확인할 항목도 함께 담았습니다.

요청 템플릿 내려받기상세 리포트발표자료

  • 요청하기 전에

    작업 폴더, 수정 가능한 범위, 만들 파일, 성공 조건을 먼저 정합니다.

  • 작업이 끝난 뒤

    파일을 직접 열고 실행 기록과 결과를 확인한 다음, 예상 밖 변경이 없는지 살펴봅니다.
