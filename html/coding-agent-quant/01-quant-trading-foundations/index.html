COURSE 01 / 17

퀀트 트레이딩의 정체

퀀트 트레이딩이 무엇이고 누가 할 수 있는지 짚은 뒤, 책이 "도구를 고르라" 고 말하는 자리에 코딩 에이전트를 놓습니다. 코드를 한 줄도 쓰지 않고 KODEX 200 가격을 받아 그리는 것으로 첫 결과를 얻습니다.

  • 4구성 영상
  • 15분영상당 최대 길이
  • 없음선행 과정

COURSE OUTCOME

네 번의 판단을 이어 첫 데이터 결과까지 갑니다

먼저 퀀트인지 판별하는 기준을 세우고, 내가 배울 준비가 됐는지 확인합니다. 그다음 Python과 Codex CLI의 역할을 나눠 작업 범위를 정한 뒤, KODEX 200 가격을 받아 결과가 요청과 일치하는지 확인합니다.

출발점

투자는 알지만 코딩은 처음인 사람

주식·ETF와 매수·매도 같은 투자 용어는 알지만 Python 문법, 터미널, 노트북 사용 경험은 전제하지 않습니다.

도착점

첫 결과를 만들고도 과장하지 않는 사람

같은 입력에서 같은 판단을 만드는 기준을 설명하고, 에이전트가 만든 파일과 실행 결과를 확인하며, 가격 그래프가 아직 백테스트는 아니라고 구분합니다.

  1. 01 퀀트의 판별 기준을 세운다

    입력·판단 기준·행동·과거 검증의 네 관문과 최종 점검표

  2. 02 학습 가능성과 실전 준비를 구분한다

    단순성 원칙과 개인 준비 항목

  3. 03 도구 선택을 작업 통제 문제로 바꾼다

    작업 폴더·권한·요청·검증 계약

  4. 04 그 계약으로 첫 결과를 만들고 확인한다

    확인 기록이 붙은 첫 노트북

과정 전체 흐름을 먼저 고정하고 영상별로 제작합니다. 아래 카드는 각 영상의 순서와 현재 공개 범위를 보여 줍니다. 상세 리포트·슬라이드·실습 자료는 해당 영상을 제작하고 검토할 때 영상별로 각각 연결합니다.
