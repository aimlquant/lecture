COURSE 01 / 17

퀀트 트레이딩과 코딩 에이전트 입문

퀀트 트레이딩의 판단 기준과 코딩 에이전트의 역할을 차례로 이해합니다. VS Code에 Codex 확장 기능과 Python·Jupyter 실습 환경을 마련한 뒤, 에이전트에게 KODEX 200 가격 파일과 노트북을 만들게 하고 직접 실행해 결과와 한계를 확인합니다.

  • 4구성 영상
  • 15분영상당 최대 길이
  • 없음선행 과정

COURSE OUTCOME

퀀트의 기준을 이해하고 코딩 에이전트와 첫 작업을 완성합니다

첫 영상에서 퀀트 규칙의 기준을 세우고, 두 번째 영상에서 코딩 에이전트가 파일과 명령을 다루는 방식을 배웁니다. 이어 VS Code 실습 환경을 완성한 뒤, 같은 폴더에서 KODEX 200 가격을 저장하고 노트북에 표와 그래프로 표시합니다.

출발점

투자는 알지만 코딩은 처음인 사람

주식·ETF와 매수·매도 같은 투자 용어는 알지만 Python 문법, VS Code, 노트북 사용 경험은 전제하지 않습니다.

도착점

코딩 에이전트와 첫 퀀트 작업을 끝낸 사람

퀀트 규칙과 코딩 에이전트의 역할을 구분하고, VS Code에서 KODEX 200 가격 파일과 노트북을 만들어 다시 실행하며, 이 결과가 아직 백테스트는 아니라고 설명합니다.

  1. 01 퀀트의 판단 기준을 이해한다

    입력·판단 기준·행동·과거 검증의 네 관문과 최종 점검표

  2. 02 코딩 에이전트의 역할과 한계를 구분한다

    파일·코드·명령을 다루는 작업 흐름과 사람의 확인 책임

  3. 03 VS Code 실습 환경을 완성한다

    Codex 확장 기능·Python·Jupyter·강의 전용 작업 폴더

  4. 04 첫 퀀트 작업을 맡기고 실행한다

    로컬 가격 파일과 다시 실행되는 KODEX 200 노트북

과정 전체 흐름을 먼저 고정하고 영상별로 제작합니다. 아래 카드는 각 영상의 순서와 현재 공개 범위를 보여 줍니다. 상세 리포트·슬라이드·실습 자료는 해당 영상을 제작하고 검토할 때 영상별로 각각 연결합니다.
