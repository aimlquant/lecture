KODEX 200 가격을 노트북에 표시해 보기

영상에서 실제로 실행한 노트북과 CSV를 같은 폴더 구조로 내려받아 사용하세요. 프롬프트부터 다시 따라 하거나, 완성본을 열어 Run All로 결과를 확인할 수 있습니다.

노트북 내려받기가격 CSV실습 프롬프트requirements.txt

권장 폴더 구조: 프로젝트 폴더 아래 data/kodex200_price.csv와 notebooks/kodex200_price.ipynb를 둡니다. 노트북을 새 커널에서 열고 위에서 아래로 모든 셀을 실행하세요.

  • 데이터 확인

    종목과 기간, 첫·마지막 날짜, Open·High·Low·Close·Volume·Change 열을 확인합니다.

  • 노트북 확인

    표의 앞뒤 행과 Close 선 그래프가 나타나는지 살펴봅니다.

  • 재실행

    커널을 다시 시작한 뒤 Run All을 실행해 로컬 CSV에서 같은 표와 그래프가 만들어지는지 확인합니다.
